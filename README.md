# Recall · 原文刷题

将个人已整理的考拉复习资料转为阅读练习：听力 Task 2（75篇）、Task 3（56篇）、Task 4（81篇），以及阅读选择题（39篇，原题库标为 Task 3）。合计 251 篇、803 题。

## 使用

打开 index.html 即可使用，无需安装依赖。GitHub Pages 从 main 分支根目录部署。

- 原文阅读、逐题选择、整篇提交评分与答案解析
- 中文译文开关、顺序连刷、随机排序、高频排序
- 未完成筛选、错题重刷、收藏、搜索
- 本机自动保存与进度 JSON 导入/导出（不自动跨设备同步）

原文和选项来自已保存的复习资料，中文摘要沿用个人复习笔记。同篇多版本按此前人工语义去重结果合并；不同考点保留。答案与选项从对应原始题目逐项匹配，未生成干扰选项。网页为静态个人复习工具，数据不是考试预测保证。

## 开发

原生 HTML/CSS/JavaScript，无第三方前端依赖。data.js 只含学习内容，不含账户、令牌、音频地址或练习记录。用户成绩仅存储在浏览器 localStorage。

## 口语与科目切换

新增「听力 / 阅读 / 口语」科目切换，每科下选择 Task。阅读保留原题库 Task 3 编号。口语 Task 1 收录30篇、210句，含原文、校订译文、记忆要点、英文遮挡和逐句复述自评。自评结果独立于选择题正确率；不进行录音或自动口语评分。现在总计281篇，803道选择题和210句复述。
